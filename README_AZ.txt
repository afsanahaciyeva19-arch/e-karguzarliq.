ELEKTRON KARGÜZARLIQ — TELEFON + KOMPÜTER ÜÇÜN WEB PROQRAM
===========================================================
Bu versiya Windows, macOS, Android və iPhone-da eyni internet linki ilə işləyir.

Yerləşdirmə: GitHub-a yükləyin, Render.com > New > Blueprint seçin və repozitoriyanı qoşun.
render.yaml serveri və daimi disk konfiqurasiyasını hazırlayır.

Telefon: Android/Chrome > Install app / Add to Home screen.
iPhone/Safari > Share > Add to Home Screen.

Vacib: proqramda hələ istifadəçi giriş/parol sistemi yoxdur. Məxfi sənədlər üçün ictimai yayımdan əvvəl giriş sistemi əlavə edin.
